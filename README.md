# IT-566 Expense Tracker Project

Simple expense tracker made for class.

## How to run
```
python main.py
```

## Features
- Add expense (amount, category, date)
- Show all expenses
- Filter by category
- Filter by date range
- Save to JSON file
- Export to CSV (open in Excel)

## Files
- main.py - main program
- storage.py - save and load functions
- expenses.json - created when you save
- expenses.csv - created when you export

Just a beginner project. Still learning.
